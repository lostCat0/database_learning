关系数据库：一切皆二维表

上一章你认识了数据模型的骨架。本章的主角是关系模型——当今所有主流数据库（MySQL、PostgreSQL、Oracle）的理论根基。 两条主线：关系的数据结构 + 三类完整性（概念考点）和关系代数（计算考点，期末大题常客）。

关系模型的三要素（回顾第1章）：数据结构 = 二维表；数据操作 = 关系代数（集合操作）；完整性约束 = 实体、参照、用户定义三类。

一、关系的数据结构：从域到关系

1. 域 → 笛卡尔积 → 关系

这三步递进是形式化定义的必经之路：

  1. 域（Domain）：一组相同类型值的集合。例如：学号 = {S1, S2, S3}，性别 = {男, 女}。
  2. 笛卡尔积：所有域中取值的全部组合。学号 × 性别 = { (S1,男), (S1,女), (S2,男), … } 共 3×2=6 个元组。
  3. 关系：笛卡尔积的有意义的子集。比如现实中有意义的是 (S1,男), (S2,女) —— 这 2 个元组组成「学生」关系。

2. 二维表的术语对照（必背）

关系术语日常叫法说明
关系（表）一张二维表关系必须是规范的：每个分量是不可再分的数据项（第一范式）
元组行 / 记录表中的一行
属性列 / 字段表中的一列，属性个数称为「目」（n 元关系）
候选码能唯一标识一行的列唯一标识元组且无多余属性；一个关系可有多个候选码
主码主键从候选码中选定的一个；每个关系只能有一个
外码外键不是本表的码，却对应别的表的主码；用来把表连起来
「候选码中的属性叫主属性，不在任何候选码中的叫非主属性」——选择/判断题常考。另一高频判断点：关系是笛卡尔积的有意义子集，但笛卡尔积本身不是关系（有些教材表述为基本关系的每个分量必须是不可分的数据项）。

二、三类完整性约束（简答/设计题必考）

1. 实体完整性（Entity Integrity）
主属性不能取空值（NULL）。理由：主码用来唯一标识元组，若为空或部分为空，元组就失去了身份。
2. 参照完整性（Referential Integrity）
外码的取值只有两种可能：空值，或被参照表中某个真实存在的主码值。 例：选课表 SC 的「学号」参照 Student 表的「学号」，你不能给一个不存在的学生记成绩。
3. 用户定义的完整性（User-defined Integrity）
针对具体业务的约束：如成绩 ∈ [0,100]、性别 ∈ {男, 女}、学号必须唯一。
记忆钥匙：实体完整性管「自己的主码」，参照完整性管「引用别人的外码」。注意参照完整性允许外码取空——除非该属性同时是主属性。简答题要求「举例说明」时，用 Student / SC 两表最稳。

三、关系代数：考卷上的 SQL

关系代数用「对关系的运算」表达查询。分两类：

1. 传统集合运算（要求两关系「目相同」，即属性个数相同）

运算记号结果
并（Union）R ∪ S属于 R 或属于 S 的元组
差（Difference）R − S属于 R 但不属于 S 的元组
交（Intersection）R ∩ S既属于 R 又属于 S 的元组（可由差推出：R−(R−S)）
笛卡尔积R × S所有元组的拼接；m 目 × n 目 = m+n 目，k1×k2 个元组

选择 σ（Selection）——「挑行」
σ年龄>19(Student) → 只剩李四那一行。从行的角度，水平切分。
投影 π（Projection）——「挑列」
π姓名,年龄(Student) → 只有姓名、年龄两列（元组会自动去重）。从列的角度，垂直切分。
连接 ⋈（Join）
把两张表按条件拼起来。三种要分清： θ连接（按任意比较条件）、等值连接（条件为 =，保留重复列）、 自然连接（比较属性相同且去掉重复列——最常用）。自然连接 Student ⋈ SC 按「学号」对上，结果共 4 列。
除 ÷（Division）
π课程号(SC) 的全部值是 {C1, C2}。SC ÷ (σ方式求出的{C1,C2}) → 结果 {S1}， 因为只有 S1 同时选了 C1 和 C2 两门课。除运算专门回答「…全部…」类查询。
关系代数综合题的标准套路：「查询选修了全部课程的学生姓名」= π姓名( (π学号,课程号(SC) ÷ π课程号(Course)) ⋈ π学号,姓名(Student) )。 记住两个判别信号：见「至少/全部/所有」想除法；见「同时满足条件」想选择；见「只要某几列」想投影。

四、与 MySQL 的联系

关系代数就是 SQL 查询的「数学语言」：

-- σ（选择）≈ WHERE
SELECT * FROM student WHERE age > 19;

-- π（投影）≈ SELECT 列清单
SELECT name, age FROM student;

-- ⋈（自然连接）≈ JOIN ... ON
SELECT s.name, sc.cno FROM student s JOIN sc ON s.sno = sc.sno;

-- ÷（除法）没有直接运算符，用 NOT EXISTS 双重否定实现（第3章讲）

以后写 SQL 卡住时，先想「这个问题用 σ、π、⋈、÷ 怎么表达」，再翻译成 SQL，思路会清晰得多。
